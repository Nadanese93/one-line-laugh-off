Entry for the [One-Line Laugh-Off](https://make.fun/bounty/u-zkhiel-one-line-laugh-off-714618ae) bounty on make.fun: one funny line, written by `main.py` to `/output/entry.txt`.

## The joke

> My dentist asked if I floss. I said 'emotionally, yes' — he charged me extra for the honesty.

## How it works

`main.py` validates the line (1–200 characters, not whitespace-only) and writes it atomically to `entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).
